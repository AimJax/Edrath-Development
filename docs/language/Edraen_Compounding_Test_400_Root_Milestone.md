# EDRAEN COMPOUNDING TEST — 400-ROOT MILESTONE

**Status:** Exploratory Analysis — Not Canon  
**Scope:** First practical audit of the two approved compound patterns  
**Dictionary size:** 400 approved roots  
**Canon changes:** None

## Purpose and method

The initial 400-root milestone is complete. This test applies the current rules without adding linking vowels, endings, or sound changes. Trial forms are examples for evaluation, not newly approved vocabulary.

- **Pattern A:** describing root + main concept root; the final root names the main concept.
- **Pattern B:** main concept root + state or quality root; the second root gives the concept's state or quality.

## 3. What the test reveals

### Pattern A and Pattern B can overlap

**GULV** means “green,” a quality. Both **GULV + TOL = GULVTOL** and **TOL + GULV = TOLGULV** can be interpreted as “green tree.” The current rules do not say whether these forms express different nuances, are interchangeable, or whether one order should be preferred.

**Open question:** establish a convention for choosing between the patterns when a describing root is also a state/quality root.

### Root boundaries can create new sound sequences

**ZUL + LUTH = ZULLUTH** follows direct joining and preserves both spellings, but creates **LL**. The current conventions do not say whether doubled consonants are lengthened, pronounced as one consonant, or only preserved in spelling. Dense consonant clusters may raise similar questions. This test does not invent a sound change to resolve them.

**Open question:** collect more boundary examples before deciding whether a general pronunciation rule is needed.

### Three-root compounds need a dedicated test

The foundation permits two or more roots, but its explicit examples use two. **GURV + NHUR + AETH = GURVNHURAETH** could mean “bright night-sky,” but modifier order and nested interpretation are not fully specified.

**Open question:** test multiple modifiers after clarifying two-root usage.

### Literal meaning and conventional meaning are different

A transparent compound can later acquire figurative or culturally conventional meanings. This test assigns no cultural history, idiom, or lore to its trial forms.

## 4. Results and recommendations

| Question | Result |
|---|---|
| Does Pattern A produce understandable compounds? | Yes, especially material/object and descriptive/concept pairs. |
| Does Pattern B produce understandable compounds? | Yes, especially concept + physical state or quality. |
| Is every possible combination useful? | No; semantic compatibility and context still matter. |
| Do the patterns always yield distinct meanings? | No; “green tree” can be composed in either order. |
| Are boundary pronunciation rules complete? | No; doubled consonants and clusters remain open. |
| Are three-root compounds fully specified? | Not yet; modifier order needs testing. |
| Did this document change canon? | No. |

Recommended next steps: keep both patterns unchanged for now; clarify when each pattern should be preferred; test consonant boundaries; then test three-root ordering. Only revise the Language Foundation or Canon Registry after the creator approves a rule change.

**Canon boundary:** This report is exploratory. Trial forms are not approved dictionary entries and do not change the established meaning of any root.
